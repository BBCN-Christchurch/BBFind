# Image and photo management — supplement to the project brief

These requirements supplement PROJECT_BRIEF.md and apply across the initial release.

## Organisation profiles

One primary logo/profile image and an optional gallery of additional images that explain the organisation and its activities.

## Programmes, activities and services

Each individual listing supports its own primary image and additional gallery images. Attach images to that listing; do not substitute its parent organisation's gallery.

## Venues for hire

Each venue supports a featured image and multiple photographs showing rooms, facilities, outdoor areas, equipment and layouts. Support individual captions and an accessible larger gallery/lightbox.

## Upload and management

Owners can upload, replace, reorder and delete their images in their dashboard. All public image changes, including captions, featured selection, order and removal, use BBCN moderation. Retain the currently approved gallery while changes await review. Admins can approve or reject individual images.

Accept JPG/JPEG, PNG and WebP. Validate actual file contents, size and dimensions; automatically optimise and resize, and generate listing/search thumbnails. Store files in application storage with database links to the owning organisation and individual listing.

## Privacy and security

Images remain private until approved. Only the owning organisation and authorised BBCN admins can manage them. Prevent unauthorised uploads/access, remove sensitive embedded metadata, and use opaque public URLs without private registration information or original filenames.

Design for future event photographs without building an events system now.
